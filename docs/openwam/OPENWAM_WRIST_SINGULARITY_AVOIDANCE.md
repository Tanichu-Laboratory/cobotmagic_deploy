# Piper手首の特異姿勢回避（2026-09-24）

## 実装

両腕のIKに適用。待機腕を分類・固定せず、Piperのq[4]（0始まり）が0付近でq[3]/q[5]軸を整列させる特異姿勢を対象とする。全種類の特異点や自己衝突を回避する仕組みではない。

- 実測・通常IK解・制限後の解・前回送信角のいずれかの手首曲がりが15°未満、またはIK解が手首の符号を跨ぐ場合に回避処理を実施。
- 実測側の曲げ方向を維持。最小6°、望ましい曲がり12°。既に6°未満で変化量制限が小さい場合は、制限内で段階的に離脱する。
- SLSQP制約付き最適化。位置誤差上限3 mm、姿勢誤差上限8°。位置誤差を目的関数でも強く抑え、前回送信角との連続性と手首の曲がりを評価。
- URDF関節範囲と既存の実測角からの変化量制限を維持。追加でq[3]/q[5]は前回送信角から各±0.10 rad（約5.73°）以内に制限。これは速度・加速度を厳密に制御する軌道生成ではなく、回避作動中の1指令当たりの制限。
- 通常姿勢では従来の解法のまま。グリッパー値は保持。腕を使わないと決めつけて固定しない。
- 誤差・関節制約をfloat32送信候補で再確認。制約が両立しなければacceptable=false。従来の両腕判定により、その周期の両腕指令を見送る。危険な元の解へ戻して送信しない。
- 前回角はROS publish後のみ更新。IK失敗時は更新せず、左右独立。
- ログのik_diagnostics_left/rightにwrist_singularity_avoidance（作動、曲げ方向、基準角、実現可否、理由）を追加。従来のsolution_*は通常の制限前IK解の診断として保持。回避時の最終受入はguard.feasibleと最終残差による。

## 040452実行後の修正：腕全体の判定と片腕保持

前回の手首q[4]判定は今回の失敗を検出できなかった。040452は52指令すべてguard.active=false。
左q[4]は15°未満へ入らない一方、全6軸の幾何Jacobianの条件数は送信指令step36で約50.7、step40で約62.3、step51で約210.8。
したがって「手首が曲がっていれば特異姿勢ではない」という前回の判定範囲が不足していた。

変更:
- 校正済みツール位置を含む6×6幾何Jacobianを追加。位置[m]と0.25×回転[rad]で条件数を算出。全種類の特異性を単一関節角より広く検出するが、自己衝突や全経路の安全性を保証する指標ではない。
- 通常解・実測・前回指令の条件数35以上でも回避を作動。回避解には条件数40以下の制約を追加。
- 開始時に既に条件数が高い場合、既存の移動上限内で段階的に改善できるよう、その回の上限をmax(40, 実測条件数×0.9)とする。開始直後から40以下を保証するという意味ではない。
- 回避中は全6軸に前回送信角から±0.10 radの制限。実測角基準の既存上限も維持。
- 許容位置3 mm・姿勢8°の中で特異性を抑えた解がなければ、最後の送信姿勢が条件数40以下・関節範囲内・実測からの移動上限内である場合だけ、その腕を保持する。
- 保持ではグリッパーも前回値を維持し、未送信の開閉状態遷移は確定しない。
- 保持した腕のtarget_reached=false、guard.mode=hold_last_safe、実際のモデル目標との差をログに記録する。保持時はモデル目標の3 mm/8°以内を保証しない。これらの誤差上限は追従解に適用。
- 片腕の保持で他方を停止しない。安全条件を満たす保持姿勢もない場合は従来どおり当該周期を棄却。
- 姿勢保持になった場合にブリッジが警告を表示。

今回のログでの検証:
- 新指令へ理想的に追従する連続再生: 左の条件数最大40.000005（丸め誤差を含む）。step38〜51の14指令は左を保持。右は52指令すべて継続、条件数最大24.16。
- 回避しながら追従できた左指令の位置誤差最大0.123 mm、姿勢誤差最大8°。
- 元の実測・指令を固定した単発再求解では18件作動、3件棄却。既に悪い姿勢に入った旧指令をそのまま安全な保持姿勢として使うことはしない。
- 全関連テスト70件成功。解析Jacobianと有限差分の条件数一致、手首が曲がっていても全体特異性で作動するケース、保持と未到達の区別を追加検証。
- 左の求解時間P95は連続再生で約191 ms、記録観測からの再求解で約245 ms。回避時は5 Hzの周期を超える場合があり、実機での周期は未検証。

現在の設定は全体判定を有効化済み。ブリッジ再起動で反映。実機操作・稼働プロセス再起動は未実施。
数値は logs/openwam_tracking_diagnosis/whole_arm_guard_replay.json。
